# KQL Detection Queries

This folder contains Kusto Query Language (KQL) detection queries developed for endpoint telemetry analysis and threat detection. These queries developed during the implementation of the dissertation project.

## Detection Use Cases

- PowerShell Activity Detection.
- Failed Login Detection.
- Process Creation Monitoring.
- Local User Creation Detection.
- Sysmon Event Monitoring.
- Brute Force Attempt  Detection.


## Platform
Microsoft Sentinel


## Purpose

These queries were used to analyze endpoint telemetry, validate log ingestion, create analytics rules, generate alerts, and support incident investigation in a controlled SOC-style monitoring environment.
